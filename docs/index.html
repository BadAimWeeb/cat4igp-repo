CAT4IGP package repository

Signed Linux client packages. Keep your distribution’s existing repositories enabled for dependencies.

Before trusting any key, check it against the fingerprints in the installation guide. Run package manager commands as root.

Debian 13 (trixie)

Save the verified OpenPGP key as /etc/apt/keyrings/cat4igp.asc, readable by APT. Add this line to /etc/apt/sources.list.d/cat4igp.list:

deb [signed-by=/etc/apt/keyrings/cat4igp.asc] https://c4i-repo.badaimweeb.me/debian trixie main
apt-get update -o APT::Update::Error-Mode=any && apt-get install cat4igp-client

Alpine 3.24

Save the verified Alpine key in /etc/apk/keys/ under its original name. Add this line once to /etc/apk/repositories:

https://c4i-repo.badaimweeb.me/alpine/v3.24
apk update && apk add cat4igp-client

Arch Linux (x86-64)

Import the verified OpenPGP key with pacman-key --add cat4igp.asc, then locally sign its verified fingerprint with pacman-key --lsign-key. Add this section once to /etc/pacman.conf:

[cat4igp]
SigLevel = Required
Server = https://c4i-repo.badaimweeb.me/arch/$arch
pacman -Syu cat4igp/cat4igp-client

OpenWrt 25.12.5

Save the verified OpenWrt key in /etc/apk/keys/ under its original name. Put the URL matching your firmware target in /etc/apk/repositories.d/cat4igp.list:

  • x86/64: https://c4i-repo.badaimweeb.me/openwrt/25.12.5/x86_64/packages.adb
  • armsr/armv8: https://c4i-repo.badaimweeb.me/openwrt/25.12.5/aarch64_generic/packages.adb
apk update && apk add cat4igp-client

Portable Linux binaries

Download v0.1.0 for x86-64 or ARM64. Verify SHA256SUMS against its OpenPGP signature using the verified key, then check the checksum of your download before running it.

After installation

Packages do not start the daemon automatically. Review /etc/cat4igp/client.toml, start the service, and enroll using a trusted bundle from your operator. See the installation guide.
